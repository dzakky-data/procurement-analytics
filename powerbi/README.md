# Power BI — Procurement Spend Analysis

## Overview
This Power BI report provides an interactive executive overview of procurement spending, purchase orders, baseline amounts, and cost savings.

## Dashboard Features
- Total Spend, Total PO, Total Baseline, Total Cost Saving, and Saving % KPIs
- Spend analysis by department, vendor, and category
- Monthly procurement spending trends
- Interactive filters for year, department, and category

## How to Open
1. Download `Procurement_Analytics.pbix` from this folder.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard using the interactive filters.

## Data and Refresh
- All procurement data is synthetic and created for portfolio demonstration.
- The report uses Import storage mode, so the saved dataset is included in the PBIX file.
- Refreshing the data requires access to a compatible SQL Server data source. The original local database is not publicly accessible.
